# ArtLife Seoul

Seoul culture curation landing page for exhibitions, classical concerts, and theater.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- React hooks

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run lint
npm run build
npm audit
```

## Vercel Deployment

This project is ready for Vercel's Next.js preset.

- Framework preset: `Next.js`
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: auto-detected by Vercel
- Node.js: `>=20.9.0`

The deployment settings are also defined in `vercel.json`.
